# Add and Open Shapefiles in Syncfusion Blazor Maps

## Overview

This sample demonstrates how to load and display shapefile data using the Syncfusion [Blazor Maps](https://www.syncfusion.com/blazor-components/blazor-map) component. The application shows how geographic shape data can be rendered from a shapefile source and visualized within an interactive Blazor map. This approach is useful for displaying regional boundaries, administrative areas, custom geographic data, and GIS-based visualizations without relying solely on online map tile providers. The sample provides a practical reference for integrating shapefile-based map rendering into Blazor applications.

## Key Features

- Demonstrates rendering shapefile-based geographic data in the Syncfusion Maps component.
- Shows how shape data is loaded and displayed as a map layer.
- Illustrates custom geographic boundary visualization using shapefile resources.
- Provides a Blazor implementation for displaying vector-based map data.
- Uses the Maps component to render shapes from locally available geographic resources.
- Demonstrates map visualization scenarios that require custom shape data instead of standard tile maps.

## Prerequisites

- Visual Studio 2022 or Visual Studio Code
- .NET SDK compatible with the project's target framework

## How to Run the Project

**Visual Studio 2022**

1. Clone or download this repository.
2. Open the available `.sln` file if present; otherwise open `BlazorApp1.csproj`.
3. Restore all NuGet packages.
4. Set `BlazorApp1` as the startup project if required.
5. Build the project.
6. Run the application using `Ctrl+F5`.
7. Open the local URL displayed by the application in your browser.

**Visual Studio Code**

1. Clone or download this repository.
2. Open the repository folder in Visual Studio Code.
3. Open the integrated terminal.
4. Navigate to the project directory containing `BlazorApp1.csproj`.

```bash
dotnet restore
dotnet run
```

5. Open the local application URL displayed in the terminal after the application starts.
